# 🎓 Requisitos para el Certificado del Rust Bootcamp

Resumen detallado de los requisitos para obtener la certificación oficial del **Rust Bootcamp (Dev3pack x Solana)**, extraído directamente de lo comunicado por los organizadores e instructores en las sesiones grabadas.

---

## ✅ Checklist de Requisitos

- [ ] **Completar los Quizzes de la plataforma** (mínimo **40%** para ser elegible; idealmente todos).
- [ ] **Completar los ejercicios de Rust** (*Rust assignment* / PRs semanales, ej. `ex01`, `ex02`...).
- [ ] **Desplegar un programa en Solana Devnet (*Capstone*)** y enviar la dirección del programa desplegado (*deployed program address*).

---

* **Sesión 1 `[0:05:45]`–`[0:05:49]`:** Se indica que al alcanzar el **40% de progreso** te volvés elegible para recibir el certificado (si además desplegás un programa en Solana).

  🔗 [Transcripción Sesión 4](../rust%20bootcamp/transcripciones/transcripcion_rust_session_4.txt) · [Resumen Sesión 4](../rust%20bootcamp/resumen/04-wallets-seguridad-y-multisig.md)

### 2. Ejercicios de Rust (*Rust Assignment* / Pull Requests)
* **Sesión 4 `[0:01:37]`–`[0:07:58]`:** Revisión de entregas semanales mediante Pull Requests (PRs).
